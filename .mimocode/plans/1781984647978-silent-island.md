# Plano: MCP Server para CV Generator RAG

## Visão

Criar um servidor MCP (Model Context Protocol) que expõe as funcionalidades do CV Generator RAG como ferramentas para IA coding agents. Funciona com MiMo Code, Claude Code e Codex.

O servidor roda como processo STDIO local, chama o backend Django via HTTP, e gerencia autenticação por sessão automaticamente.

## Estrutura de Arquivos Chave

### `src/session.ts` — Cookie jar + CSRF
- `SessionManager` mantém cookies em memória
- `updateFromResponse()` extrai Set-Cookie
- `getCookieHeader()` monta header Cookie
- `refreshCsrf()` busca token via `GET /api/auth/session/`
- Requests POST/PUT/DELETE incluem header `X-CSRFToken`

### `src/client.ts` — HTTP wrapper
- `sessionFetch(method, path, body?)` — fetch com cookies + CSRF automáticos
- `sessionFetchMultipart(path, formData)` — para uploads
- Timeout configurável (120s para geração, 30s para resto)
- Erros 401/403 → mensagem "Sessão expirada, faça cv_login"
- Erros de rede → "Backend indisponível. Docker rodando?"

### `src/tools/cv.ts` — cv_generate (tool principal)
- Faz POST `/api/generate/` com job_description
- Parseia SSE stream (resposta contém `data: {"chunk": "...", "photo_url": "..."}`)
- Retorna `{ markdown, photo_url, word_count, tip }` (tip baseado no tamanho)

### `src/tools/system.ts` — cv_dashboard (composto)
- Chama em paralelo: providers-status, documents, generated-cvs, interviews, profile
- Agrega em um objeto único com métricas (total docs, avg score interview, completeness do profile)

### `src/utils.ts` — SSE parser + helpers
- `parseSSEStream(response)` → lê body completo, extrai JSON do `data:`
- `successResult(data)` / `errorResult(msg)` → formato MCP padrão

## Autenticação

O backend usa Django session auth + CSRF. O MCP server:
1. Chama `cv_login` uma vez → armazena sessionid + csrf cookie
2. Todos os requests posteriores incluem `Cookie: sessionid=...; csrftoken=...`
3. POST/PUT/DELETE incluem `X-CSRFToken: <csrftoken>`
4. Se 401 → retorna erro pedindo re-login
5. Sessão vive só na memória do processo MCP
